# 金融智能投研 Agent

第二届全国人工智能应用创新大赛 参赛作品（通用赛道 · 金融方向）

一个基于大模型的**智能投研分析助手**：输入股票代码即可自动联网取数，
一键完成结构化财务分析、四维评分、趋势图表与研报生成。

> **项目定位**：面向**全行业上市公司**的通用财务投研引擎。分析对象覆盖消费、金融、
> 新能源、医药、互联网等多个行业，但工具的方法论层始终是金融的——统一的财务指标口径、
> **同业对标**、四维规则评分与风险提示。行业在其中只作为「对标参数」存在，不改变引擎的金融属性。

## 核心功能

| 功能 | 说明 |
|---|---|
| 🌐 在线自动取数 | 输入股票代码/名称，自动从巨潮资讯网 + 东方财富获取行情、多期财务指标、年报 PDF |
| 📄 年报 RAG 检索增强 | 年报按页切片向量化（ChromaDB）；分析/研报/追问自动检索相关章节，结论标注「见年报第X页」 |
| 📐 规则引擎评分 | 四维评分由固定阈值规则计算（同一数据必然同一分数），页面可展开查看每个分数的完整依据链 |
| ✅ 输出严格校验 | LLM 输出经字段/类型/范围校验，异常项自动修复或剔除，页面永不因格式问题崩溃 |
| 🔄 状态指纹管理 | 公司/报告期/年报/行业变化时统一清空旧结果，杜绝「旧公司结论残留」 |
| 📊 结构化分析 | 四维评分卡片（盈利/成长/偿债/现金流）+ 综合评分 + 指标明细 |
| 📈 可视化图表 | 关键指标柱状图 + 近五年**年报口径**趋势图（与季报数据严格区分） |
| 📝 研报生成 | 一键生成完整投研报告，可下载为 Markdown |
| ⚖️ 双公司对比 | 两家公司横向对比，自动生成对比表与综合结论 |
| 📚 行业财务基准库 | 内置 6 大行业**财务对标基准**（通用/消费/金融/新能源/医药/互联网），四维评分与四象限按同业口径差异化计算 |
| 💬 多轮追问 | 基于数据与已有结论连续对话；年报问题实时检索原文片段（带页码引用） |
| 🤖 双模型协同 | DeepSeek 出分析 + 千问二次润色 · 润色失败自动降级回原文 |
| 🧭 Agent 执行轨迹 | 第 5 个页签实时记录工具调用链（取数 → 检索 → 抽取 → 评分 → 自检）：每步的入参、产出、耗时、是否降级，以及口径锁定 / 行业识别 / 故障自愈等自主决策点 |
| 🧪 对照实验 | `eval_cases.py` 一键对比「直接大模型 vs 本 Agent」（准确性/引用/可复现性/耗时） |

## 数据来源

- **财务数据与行情**：东方财富公开接口（`datacenter-web.eastmoney.com` / `push2.eastmoney.com`）
- **公告与年报 PDF**：巨潮资讯网（官方指定信息披露平台 `cninfo.com.cn`）
- **大模型**：
  - DeepSeek（结构化推理与初稿生成）
  - 千问（DashScope / 阿里云百炼，用于 RAG Embedding + 二次润色）

## 本地运行

1. 安装依赖：`pip install -r requirements.txt`
2. 在项目根目录创建 `.streamlit/secrets.toml`，内容参考 `secrets.toml.example`
3. 启动：`streamlit run app.py`

## 部署到 Streamlit Cloud

1. 把整个文件夹推送到 GitHub 公开仓库
2. 登录 https://streamlit.io/cloud ，用 GitHub 账号授权
3. New app → 选仓库 → main 分支 → app.py
4. 在 Advanced settings → Secrets 里粘贴：

```toml
DEEPSEEK_API_KEY = "sk-你的新key"
QWEN_API_KEY = "sk-你的千问key"  # 申请: https://bailian.console.aliyun.com
APP_USER = "自定义账号"
APP_PASSWORD = "自定义密码（不要用生日/学号等弱口令）"
```

5. Deploy，等待几分钟得到 `https://xxx.streamlit.app` 公开链接
6. 提交给比赛时，把这个链接 + 访问账号密码一并附上（见 PPT 第 19 页）

> ⚠️ **不要把真实账号密码写进 README 再推到公开仓库**。仓库是公开的，
> 口令一旦上网，任何人都能登录并消耗你的 API 额度（`DAILY_LLM_LIMIT` 熔断
> 触发后，评审期间你自己反而用不了）。真实凭据只写在两处：
> Streamlit Cloud 的 Secrets 面板，以及提交给评委的 PPT 第 19 页。

## 安全说明

- 代码中**不含任何密钥**，全部从环境变量 / Streamlit Secrets 读取
- `.streamlit/secrets.toml` 已被 `.gitignore` 排除，不会推送到 GitHub
- 建议为应用设置访问账号密码，避免 API 额度被滥用
- 评审期建议同时设置 `DEMO_KEY`（演示令牌，`?key=xxx` 可免登录），
  万一账号密码在传递中出问题，评委仍有一条能进的路
