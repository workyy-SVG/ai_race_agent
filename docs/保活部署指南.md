# Streamlit Cloud 保活部署指南（5 分钟设置，防评委白屏）

## 方案一：GitHub Actions 保活（推荐，零注册）

已内置配置文件 `.github/workflows/keepalive.yml`，只要代码推送到 GitHub，保活自动生效：

1. 用 GitHub Desktop 推送任意一次改动（含该文件）
2. 打开仓库页面 → **Actions** 标签 → 左侧看到 `keepalive` → 点进去 → **Enable workflow**（如未自动启用）
3. 点 **Run workflow** 手动跑一次验证 → 显示绿色 ✓ 即生效
4. 之后它每 5 分钟自动 ping 一次应用，永不让它休眠

注意：仓库 60 天无提交时 GitHub 会自动停用定时任务，届时去 Actions 页面重新启用即可（比赛期间你会频繁提交，基本不会触发）。

## 方案二：cron-job.org（备选）

> 注册报错「创建账户时出现了错误」的排查：① 关闭代理/VPN 后无痕窗口重试；
> ② 换浏览器；③ 换邮箱（QQ 邮箱换 Gmail/Outlook）。国内 IP/数据中心 IP
> 常被其风控拦截，失败率高，建议直接用方案一。

## 为什么要保活

Streamlit Cloud 免费版应用在**闲置约 15 分钟后自动休眠**。休眠后第一个访问者
（很可能是评委）会面对 30–60 秒的白屏等待，体验极差。

解决思路：用免费的定时任务服务，每 5 分钟向应用发一次 GET 请求，让它永不休眠。

## 设置步骤（cron-job.org，免费）

1. 打开 https://cron-job.org 注册账号（邮箱即可，免费无信用卡）
2. 登录后右上角 **Cronjobs → CREATE CRONJOB**
3. 填写：
   - **Title**: `ai-race-agent-keepalive`（随意）
   - **URL**: `https://airaceagent-gzelpcnnkfdpvgwgkii97oj.streamlit.app`
     （注意：填你自己的应用地址，不要带 `/` 以外的路径）
   - **Execution Schedule**: 选 **Every 5 minutes**（每 5 分钟）
4. 点 **CREATE** 保存，然后把右上角开关切到 **Enabled / 激活**
5. 验证：等 10 分钟后打开一个**无痕浏览器窗口**访问你的应用——
   如果几秒内就出登录页（而不是白屏转圈），说明保活生效

## 注意事项

- **别填登录后的页面地址**，填应用根地址即可，登录页本身就能保活
- cron-job.org 免费版每 5 分钟一次完全够用；如果某天它抽风停了，
  应用最多恢复到"闲置 15 分钟后休眠"的原状，不会更糟
- 国内访问 cron-job.org 偶尔慢，但任务在它服务器上执行，不影响你本地网络
- 若不想用第三方服务，替代方案：
  - 手机设个闹钟，每天答辩/评审前手动打开一次应用（最低保底）
  - 用另一台常开电脑跑 `while true; do curl -s <你的URL> > /dev/null; sleep 300; done`
- **答辩/录制视频当天**：仍建议提前 30 分钟手动完整跑一遍流程
  （取数 → 建索引 → 分析 → 追问），保活只解决"应用醒着"，
  不解决"RAG 索引已建好"——索引建好后尽量别切换公司，演示更流畅

## 一个提醒

保活会让应用 7×24 被访问，等于应用一直"在线"。配合应用自带的
每日 LLM 熔断（DAILY_LLM_LIMIT），API 额度是安全的；但评审期间
建议把 Secrets 里的 `DAILY_LLM_LIMIT` 调到 `300`，避免评委测试时额度耗尽。
